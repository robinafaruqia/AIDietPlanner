# AI Diet Planner

A full-stack web application that generates personalized weekly meal plans using Google Gemini AI, based on user biometrics and health conditions. Features comprehensive nutrition tracking inspired by Cronometer.

## Features

### Meal Planning
- **AI-Powered Meal Plans**: Personalized weekly meal plans generated by Google Gemini AI
- **Dynamic Health Conditions**: Select multiple conditions from a searchable Select2 dropdown, or add custom conditions
- **Weekly Planning**: Complete 7-day meal plans with breakfast, lunch, dinner, and snacks
- **AI-Generated Grocery Lists**: Smart shopping lists with quantities organized by category
- **Nutritional Information**: Detailed calorie and macronutrient breakdown for each meal

### Nutrition Tracking (Cronometer-Inspired)
- **Daily Food Diary**: Log meals with full macro and micronutrient tracking
- **Exercise Logging**: Track workouts and calories burned
- **Energy Balance**: Visual display of calories in vs calories burned
- **Macro Tracking**: Protein, carbs, fat, fiber with progress bars and doughnut charts
- **Water Intake**: Interactive glass-based water tracker
- **Mood Tracking**: Daily mood logging with emoji selector
- **Biometrics**: Track weight, body fat percentage, and waist measurements
- **Goal Setting**: Set and track daily calorie and macro goals with a built-in calculator
- **Progress Charts**: Visualize weight and nutrition trends over time
- **Streak Tracking**: Stay motivated with consecutive day logging streaks

### Health Conditions Supported
- Gallstones (low-fat meals)
- Diabetes (low-carb, diabetic-friendly)
- High Blood Pressure (low-sodium, heart-healthy)
- Heart Disease (low-fat, nutrient-rich)
- Obesity (high-protein, calorie-controlled)
- Kidney Disease (low-protein, low-sodium)
- PCOS (low glycemic index)
- Celiac Disease (gluten-free)
- IBS (low-FODMAP friendly)
- Custom conditions (user-defined)

## Technologies Used

- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **AI**: Google Gemini API (@google/genai)
- **Frontend**: EJS templates, Bootstrap 5, jQuery
- **UI Components**: Select2 (searchable dropdowns), Chart.js (visualizations)
- **Security**: express-session, input validation, XSS prevention

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd AIDietPlanner
```

2. Install dependencies:

```bash
npm install
```

3. Set up environment variables:

```bash
cp .env.example .env
```

Edit `.env` and configure:

```
PORT=3000
MONGODB_URI=mongodb://localhost:27017/ai-diet-planner
SESSION_SECRET=your-secret-key-here-minimum-32-characters
GOOGLE_AI_API_KEY=your-google-gemini-api-key-here
NODE_ENV=development
```

**Getting Google Gemini API Key:**
1. Visit: https://aistudio.google.com/apikey
2. Click "Create API Key"
3. Copy the key and add it to `.env` as `GOOGLE_AI_API_KEY`

4. Make sure MongoDB is running (local or Atlas)

5. Start the server:

```bash
npm start
```

For development with auto-reload:

```bash
npm run dev
```

6. Open your browser and navigate to `http://localhost:3000`

## Usage

### Creating a Meal Plan
1. Navigate to the "Create Plan" page
2. Enter your weight (kg) and height (cm)
3. Select health conditions from the dropdown (or type custom ones)
4. Check "Include Grocery List" if desired
5. Click "Generate Meal Plan"
6. View your AI-generated weekly meal plan
7. Click the + button on any meal to log it to your nutrition tracker

### Tracking Nutrition
1. Navigate to the "Tracking" page
2. Use date navigation to select the day
3. Add meals via the "Add Food" button or log from meal plans
4. Log exercises with the "Add Exercise" button
5. Track water intake by clicking the glass icons
6. Set your mood for the day
7. Log biometrics (weight, body fat, waist) periodically
8. Set goals using the goal calculator

## API Endpoints

### Meal Plans
- `POST /api/meal-plan/generate` - Generate a new AI meal plan
- `GET /api/meal-plan/:id` - Get a specific meal plan
- `GET /api/meal-plan` - Get all meal plans

### Nutrition Tracking
- `GET /api/nutrition/:date` - Get nutrition log for a date
- `POST /api/nutrition/log` - Log a meal
- `POST /api/nutrition/log/from-plan` - Log a meal from generated plan
- `DELETE /api/nutrition/meal/:date/:mealId` - Remove a logged meal
- `POST /api/nutrition/exercise` - Log an exercise
- `DELETE /api/nutrition/exercise/:date/:exerciseId` - Remove an exercise
- `PUT /api/nutrition/goals/:date` - Update daily goals
- `POST /api/nutrition/goals/calculate` - Calculate recommended goals
- `PUT /api/nutrition/biometrics/:date` - Update biometrics
- `PUT /api/nutrition/mood/:date` - Update mood
- `PUT /api/nutrition/water/:date` - Update water intake
- `GET /api/nutrition/history/:days` - Get historical data
- `GET /api/nutrition/biometrics/history/:days` - Get biometrics history
- `GET /api/nutrition/streak` - Get current logging streak

## Deployment

### Using Docker Compose (Recommended)

1. Start all services (app + MongoDB):

```bash
docker compose up -d
```

2. Access the application at `http://localhost:3000`

3. Stop services:

```bash
docker compose down
```

### Using Docker (Manual)

1. Build the Docker image:

```bash
docker build -t ai-diet-planner .
```

2. Run the container:

```bash
docker run -p 3000:3000 --env-file .env ai-diet-planner
```

### Using Heroku

1. Install Heroku CLI and login:

```bash
heroku login
```

2. Create a new app:

```bash
heroku create your-app-name
```

3. Set environment variables:

```bash
heroku config:set MONGODB_URI=your-mongodb-uri
heroku config:set SESSION_SECRET=your-secret-key
heroku config:set GOOGLE_AI_API_KEY=your-api-key
heroku config:set NODE_ENV=production
```

4. Deploy:

```bash
git push heroku main
```

### Using Railway/Render

1. Connect your GitHub repository
2. Set environment variables in the platform dashboard
3. Deploy automatically on push
