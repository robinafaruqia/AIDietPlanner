# AI Diet Planner

A full-stack web application that generates personalized weekly meal plans using Google Gemini AI, based on user biometrics and health conditions. Features comprehensive nutrition tracking inspired by Cronometer, user authentication, and weight management.

## Features

### User Authentication
- **Email/Password Registration**: Create an account with email and password
- **Google Sign-In**: Quick login with Google OAuth 2.0
- **Profile Management**: Update profile, change password, and manage account
- **Secure Sessions**: HTTP-only cookies with session regeneration

### Meal Planning
- **AI-Powered Meal Plans**: Personalized weekly meal plans generated by Google Gemini AI
- **User-Specific Plans**: Logged-in users get cached plans saved to their account
- **Dynamic Health Conditions**: Select multiple conditions from a searchable Select2 dropdown, or add custom conditions
- **Weekly Planning**: Complete 7-day meal plans with breakfast, lunch, dinner, and snacks
- **AI-Generated Grocery Lists**: Smart shopping lists with quantities organized by category
- **Nutritional Information**: Detailed calorie and macronutrient breakdown for each meal
- **Plan History**: View and reuse previously generated meal plans

### Weight Management
- **Weight Tracking**: Log daily weight with optional notes
- **Progress Charts**: Visualize weight trends over 30, 90, or 365 days
- **Goal Setting**: Set target weight and track progress percentage
- **Statistics**: Weekly/monthly change, days tracking, lowest/highest weight
- **Weight History**: Full history with edit and delete capabilities

### Nutrition Tracking (Cronometer-Inspired)
- **Daily Food Diary**: Log meals with full macro and micronutrient tracking
- **Exercise Logging**: Track workouts and calories burned
- **Energy Balance**: Visual display of calories in vs calories burned
- **Macro Tracking**: Protein, carbs, fat, fiber with progress bars and doughnut charts
- **Water Intake**: Interactive glass-based water tracker
- **Mood Tracking**: Daily mood logging with emoji selector
- **Biometrics**: Track weight, body fat percentage, and waist measurements
- **Goal Setting**: Set and track daily calorie and macro goals with a built-in calculator
- **Progress Charts**: Visualize weight and nutrition trends over time
- **Streak Tracking**: Stay motivated with consecutive day logging streaks
- **User-Specific Data**: All nutrition data is tied to your account

### Health Conditions Supported
- Gallstones (low-fat meals)
- Diabetes (low-carb, diabetic-friendly)
- High Blood Pressure (low-sodium, heart-healthy)
- Heart Disease (low-fat, nutrient-rich)
- Obesity (high-protein, calorie-controlled)
- Kidney Disease (low-protein, low-sodium)
- PCOS (low glycemic index)
- Celiac Disease (gluten-free)
- IBS (low-FODMAP friendly)
- Custom conditions (user-defined)

## Technologies Used

- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **AI**: Google Gemini API (@google/genai)
- **Authentication**: Passport.js (Local + Google OAuth 2.0), bcryptjs
- **Frontend**: EJS templates, Bootstrap 5, jQuery
- **UI Components**: Select2 (searchable dropdowns), Chart.js (visualizations)
- **Security**: express-session, input validation, XSS prevention, rate limiting

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd AIDietPlanner
```

2. Install dependencies:

```bash
npm install
```

3. Set up environment variables:

```bash
cp .env.example .env
```

Edit `.env` and configure:

```
PORT=3000
MONGODB_URI=mongodb://localhost:27017/ai-diet-planner
SESSION_SECRET=your-secret-key-here-minimum-16-characters
GEMINI_API_KEY=your-google-gemini-api-key-here

# Optional: Google OAuth (for Google sign-in)
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
GOOGLE_CALLBACK_URL=http://localhost:3000/api/auth/google/callback
```

**Getting Google Gemini API Key:**
1. Visit: https://aistudio.google.com/apikey
2. Click "Create API Key"
3. Copy the key and add it to `.env` as `GEMINI_API_KEY`

**Setting up Google OAuth (Optional):**
1. Go to https://console.cloud.google.com/apis/credentials
2. Create a new OAuth 2.0 Client ID
3. Set Authorized redirect URI to: `http://localhost:3000/api/auth/google/callback`
4. Copy Client ID and Client Secret to `.env`

4. Make sure MongoDB is running (local or Atlas)

5. Start the server:

```bash
npm start
```

For development with auto-reload:

```bash
npm run dev
```

6. Open your browser and navigate to `http://localhost:3000`

## Usage

### Creating an Account
1. Click "Sign Up" in the navigation
2. Fill in your details (name, email, password)
3. Optionally set your starting weight and target weight
4. Or use "Sign in with Google" for quick registration

### Creating a Meal Plan
1. Navigate to the "Create Plan" page
2. Enter your weight (kg) and height (cm)
3. Select health conditions from the dropdown (or type custom ones)
4. Check "Include Grocery List" if desired
5. Click "Generate Meal Plan"
6. View your AI-generated weekly meal plan
7. Click the + button on any meal to log it to your nutrition tracker

### Tracking Weight
1. Navigate to the "Weight" page (requires login)
2. Enter your current weight and optional notes
3. View your progress chart over time
4. Set a target weight to see goal progress
5. Track weekly and monthly changes

### Tracking Nutrition
1. Navigate to the "Tracking" page
2. Use date navigation to select the day
3. Add meals via the "Add Food" button or log from meal plans
4. Log exercises with the "Add Exercise" button
5. Track water intake by clicking the glass icons
6. Set your mood for the day
7. Log biometrics (weight, body fat, waist) periodically
8. Set goals using the goal calculator

## API Endpoints

### Authentication
- `POST /api/auth/register` - Create new account
- `POST /api/auth/login` - Login with email/password
- `POST /api/auth/logout` - Logout
- `GET /api/auth/google` - Start Google OAuth
- `GET /api/auth/google/callback` - Google OAuth callback
- `GET /api/auth/me` - Get current user
- `PUT /api/auth/update-profile` - Update profile
- `PUT /api/auth/change-password` - Change password
- `DELETE /api/auth/account` - Deactivate account

### Meal Plans
- `POST /api/meal-plan/generate` - Generate a new AI meal plan
- `GET /api/meal-plan/history/list` - Get meal plan history
- `GET /api/meal-plan/:id` - Get a specific meal plan
- `GET /api/meal-plan` - Get all meal plans
- `DELETE /api/meal-plan/:id` - Delete a meal plan

### Weight Management
- `POST /api/weight/log` - Log new weight entry
- `GET /api/weight/history` - Get weight history
- `GET /api/weight/stats` - Get weight statistics
- `PUT /api/weight/goal` - Set target weight
- `PUT /api/weight/entry/:id` - Update weight entry
- `DELETE /api/weight/entry/:id` - Delete weight entry

### Nutrition Tracking
- `GET /api/nutrition/log/:date` - Get nutrition log for a date
- `POST /api/nutrition/log/meal` - Log a meal
- `POST /api/nutrition/log/from-plan` - Log a meal from generated plan
- `DELETE /api/nutrition/log/meal/:date/:mealId` - Remove a logged meal
- `POST /api/nutrition/log/exercise` - Log an exercise
- `DELETE /api/nutrition/log/exercise/:date/:exerciseId` - Remove an exercise
- `PUT /api/nutrition/goals` - Update daily goals
- `POST /api/nutrition/calculate-goals` - Calculate recommended goals
- `PUT /api/nutrition/biometrics` - Update biometrics
- `PUT /api/nutrition/mood` - Update mood
- `PUT /api/nutrition/water` - Update water intake
- `GET /api/nutrition/history/:days` - Get historical data
- `GET /api/nutrition/biometrics/history/:days` - Get biometrics history
- `GET /api/nutrition/streak` - Get current logging streak
- `GET /api/nutrition/summary/weekly` - Get weekly summary

## Deployment

### Using Docker Compose (Recommended)

1. Start all services (app + MongoDB):

```bash
docker compose up -d
```

2. Access the application at `http://localhost:3000`

3. Stop services:

```bash
docker compose down
```

### Environment Variables for Production

```
NODE_ENV=production
PORT=3000
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/dbname
SESSION_SECRET=your-secure-random-string-32-chars
GEMINI_API_KEY=your-google-gemini-api-key
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
GOOGLE_CALLBACK_URL=https://your-domain.com/api/auth/google/callback
```

### Deploying to Vercel

1. Connect your GitHub repository to Vercel
2. Set environment variables in Vercel dashboard
3. Deploy automatically on push
4. For Google OAuth, update callback URL to your Vercel domain

## Security Features

- Password hashing with bcrypt (10 rounds)
- Session management with secure HTTP-only cookies
- Session regeneration on login (prevents session fixation)
- Input validation and sanitization
- XSS prevention with HTML escaping
- Rate limiting on auth routes (20 requests/15 min)
- API rate limiting (100 requests/15 min)
- Request body size limits
- Disabled x-powered-by header
- HTTPS support in production
